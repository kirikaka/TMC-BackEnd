[kirikaka/TMC-BackEnd](https://github.com/kirikaka/TMC-BackEnd) 레포지토리는 대출 상환 시뮬레이션 및 금융 정보 관리 시스템을 구축하는 Spring 기반 백엔드 프로젝트입니다. 이 프로젝트는 사용자의 대출 정보를 분석하고 최적의 상환 전략을 제시하는 금융 서비스 플랫폼의 서버 애플리케이션입니다.[1]

## 프로젝트 개요

TMC-BackEnd는 Spring Framework 5.3.37 기반의 Java 웹 애플리케이션으로, 금융 데이터 통합 및 대출 상환 시뮬레이션을 핵심 기능으로 제공합니다. 프로젝트는 CODEF API를 활용하여 실제 금융기관 데이터를 연동하며, 사용자에게 맞춤형 대출 관리 솔루션을 제공합니다.[1]

## 기술 스택

### 핵심 프레임워크 및 라이브러리
- **Spring Framework 5.3.37**: MVC, Security, WebSocket, AOP 등 종합적인 엔터프라이즈 기능 지원[1]
- **Spring Security 5.3.9**: JWT 기반 인증/인가 시스템 구현[1]
- **MyBatis 3.4.6**: 데이터베이스 매핑 및 쿼리 관리[1]
- **Redis**: Lettuce 클라이언트를 통한 세션 및 캐시 관리[1]

### 데이터베이스 및 연결
- **MySQL 8.1.0**: 메인 데이터베이스[1]
- **HikariCP**: 고성능 커넥션 풀링[1]
- **Log4jdbc**: SQL 쿼리 로깅 및 디버깅[1]

### 외부 통신 및 데이터 처리
- **OkHttp 4.12.0**: HTTP 클라이언트[1]
- **Jackson 2.15.2**: JSON 직렬화/역직렬화[1]
- **JJWT 0.11.5**: JWT 토큰 생성 및 검증[1]

## 도메인 구조

프로젝트는 명확한 도메인 주도 설계(DDD) 패턴을 따르며, 다음과 같은 주요 도메인으로 구성됩니다:[1]

### 주요 도메인
- **user**: 사용자 계정 및 프로필 관리[1]
- **auth**: 인증 및 권한 관리 (JWT, Spring Security)[1]
- **debt**: 대출 정보 관리 및 조회[1]
- **deposit**: 예적금 정보 관리[1]
- **simulation**: 대출 상환 시뮬레이션 엔진[1]
- **codef**: CODEF API 연동 및 금융 데이터 수집[1]
- **policy**: 정책 정보 및 추천 시스템[1]
- **notification**: 실시간 알림 시스템 (WebSocket)[1]
- **admin**: 관리자 기능[1]

## 주요 기능

### 대출 상환 시뮬레이션
프로젝트의 핵심 기능으로, 다양한 상환 방식(원리금균등, 원금균등, 만기일시상환 등)에 대한 시뮬레이션을 제공합니다. 최근 커밋 이력을 보면 만기일시 상환과 중도 상환 로직 개선이 활발히 이루어졌습니다.[1]

### CODEF API 연동
실제 금융기관 데이터를 수집하고 통합하여 사용자의 실제 금융 정보를 기반으로 한 분석을 제공합니다.[1]

### 실시간 알림 시스템
Spring WebSocket과 STOMP 프로토콜을 활용하여 실시간 알림 기능을 구현했습니다.[1]

### 보안 및 인증
JWT 기반의 무상태(stateless) 인증 시스템과 Spring Security를 통한 엔드포인트 보호를 적용했습니다.[1]

## 개발 현황

최근 커밋 이력을 보면 다음과 같은 개발 활동이 활발히 진행되었습니다:[1]
- 상환 시뮬레이션 로직 오류 수정 및 개선[1]
- TCS(Total Credit Service) 전략 정렬 로직 최적화[1]
- 관리자 ID 필드 리팩토링 (id → user_id)[1]
- 만기일시상환 및 중도상환 처리 로직 개선[1]

프로젝트는 체계적인 브랜치 전략과 Pull Request 기반 협업 워크플로우를 따르고 있으며, 코드 리뷰와 이슈 관리를 통해 품질을 유지하고 있습니다.[1]
